# Práctica de Comandos Básicos en HashSet (Java)

>+ ! Este repositorio es una continuación a la presentación sobre la estructura de datos (HashSet)
> contiene un ejemplo práctico y educativo en Java para demostrar el uso de las operaciones fundamentales y comandos básicos de la estructura de datos HashSet !

Descripción del Código

El programa muestra cómo declarar, manipular, consultar y vaciar un HashSet de números enteros (Integer). A continuación se detallan los métodos principales que se utilizan en la práctica:


>+ Declaración e Inicialización (new HashSet<>()): Creación de una colección de tipo HashSet para almacenar datos únicos sin un orden específico.
>
> 
>+ Inserción de elementos (add()): Agrega elementos al conjunto.
>
>
>+ Tamaño de la colección (size()): Devuelve el número actual de elementos almacenados.
>
>
>+ Vaciado del conjunto (clear()): Elimina todos los elementos contenidos en el HashSet.
>
>
>+ Comprobación de estado vacío (isEmpty()): Verifica si el conjunto se encuentra sin elementos.

>##### (Nota: Si al ejecutar notas que un orden distinto, ten en cuenta que el orden de impresión de los elementos dentro del HashSet puede variar debido a que esta estructura no garantiza un orden fijo).
